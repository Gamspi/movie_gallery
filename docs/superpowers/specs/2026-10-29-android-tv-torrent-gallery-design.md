# Android TV: галерея фильмов с торрент-стримом — дизайн

Дата: 2026-10-29

Актуализация: 2026-10-31. Это целевая спецификация, а не перечень уже готовых функций. Реализованное состояние и результаты проверки — в [STATUS](../../STATUS.md), незакрытые требования — в [BACKLOG](../../BACKLOG.md).

На базе `d1ea23e` готовы каталог, поиск раздач и торрент-плеер в объёме планов этапов 1–2; в этапе 3 выполнены задачи 1–4. Два субтитра пока не отображаются; перевод не реализован. Проверка на ТВ в последнем аудите не выполнялась.

## Цель

Личное приложение для Android TV (ставится APK вручную, без Google Play).
Каталог фильмов с постерами → выбор фильма → поиск раздач → потоковый просмотр
торрента прямо на ТВ. Выбор озвучки и два субтитра одновременно (для изучения языка).

Своего медиасервера нет и не требуется. Всё работает на ТВ.

## Не входит

- Jellyfin / Plex (нет своей коллекции)
- Публикация в Google Play, мультипользовательность
- Сериалы (только фильмы; сериалы — возможный будущий этап)
- Облачный перевод (DeepL/Claude) — возможный будущий этап

## Стек

- Kotlin, Gradle (Kotlin DSL), minSdk 26; текущие compileSdk/targetSdk — 37, версии закреплены в проекте
- Каталог: Kinopoisk API Unofficial (по умолчанию), TMDB — опционально (заблокирован в РФ geo-DNS)
- Jetpack Compose for TV (`androidx.tv:tv-material`)
- Media3 / ExoPlayer; ffmpeg-расширение (аудио DTS/TrueHD/AC3) — целевое требование, отложено, см. G-06
- libtorrent4j — торрент-движок
- ML Kit Translate (on-device) — этап 4, не реализован
- Целевой стек хранения: Room — кэш, история, настройки дорожек; DataStore — настройки. Сейчас настройки хранятся через `SecretStore`, позиции и озвучка — через SharedPreferences; решение о миграции входит в G-08
- Hilt — DI; Retrofit/OkHttp + kotlinx.serialization — сеть
- Coil — постеры

## Модули

Каждый модуль — пакет с одним публичным интерфейсом.

| Модуль | Задача | Интерфейс |
|---|---|---|
| `catalog` | Kinopoisk API Unofficial (по умолчанию) или TMDB (опционально, в РФ блок geo-DNS), выбор в настройках: популярное, жанры, поиск, карточка фильма (название, оригинальное название, год, постер, описание, imdb id) | `CatalogRepository` |
| `torrents` / `releases` | Поиск раздач по фильму, сведение результатов и экран выбора; пакет `search` занят поиском по каталогу | `TorrentProvider`, `TorrentSearch` |
| `stream` | Загрузка и стрим одного торрента | `TorrentEngine`, `StreamManager`, `StreamServer` |
| `player` | ExoPlayer, выбор аудио, оверлей двух субтитров, управление пультом | `PlayerScreen` |
| `subs` | Получение и парсинг субтитров | `OpenSubtitlesClient`, `SubtitleParser`, `SubtitleTrack`; выбор источника слоя ещё не реализован |
| `translate` | Перевод субтитров ML Kit | `SubtitleTranslator` |
| `settings` | Языки, ключи, логины, кэш | `SettingsRepository` |

### search

`TorrentProvider.search(movie: MovieDetails): List<TorrentResult>`

`TorrentResult` сейчас: название, magnet, info-hash, размер, сиды, личи, качество (2160p/1080p/720p, парсинг из названия), провайдер. Исходное требование поддержки torrent-url сохраняется как незакрытое: G-10; в текущую модель и планы этапов 2–3 оно не включено.

Провайдеры:
1. **rutor** — парсинг HTML, без логина. Поиск по русскому названию + год.
2. **YTS** — публичный JSON API, поиск по imdb id. Выключен по умолчанию.
3. **apibay (TPB)** — публичный JSON API, поиск по оригинальному названию + год.

RuTracker и Prowlarr — отложены.

`TorrentSearch` опрашивает включённые провайдеры параллельно (таймаут 15 с на каждый),
сводит, удаляет дубли по info-hash, сортирует по сидам. Упавший провайдер не ломает
выдачу — показывается пометка «rutor недоступен».

### torrent

- Добавить magnet или `.torrent`, получить метаданные; один видеофайл запускается автоматически, при нескольких показывается список по убыванию размера. Сейчас реализован только путь magnet; `.torrent` — G-10.
- Приоритет первых и последних кусков (метаданные MP4/MKV). По уточнению плана 2в флаг последовательной загрузки выключен: используются дедлайны кусков и упреждающая загрузка.
- Локальный HTTP-сервер на `127.0.0.1:<порт>` с поддержкой Range. При запросе
  диапазона поднимает приоритет нужных кусков и ждёт их.
- Готов к воспроизведению: 5% файла или 20 МБ (что меньше) с начала + последние куски.
- Статус: скорость, сиды, буфер — показывается на экране загрузки и в плеере.
- После просмотра: удалить (по умолчанию) или хранить. Лимит кэша по месту (настройка).
  Сейчас реализовано только удаление; хранение и лимит — G-05.

### player

- ExoPlayer играет URL локального HTTP-сервера.
- **Озвучка:** список аудиодорожек (язык + label, напр. «Rus, MVO LostFilm»).
  Выбранная дорожка запоминается по языку.
- **Два субтитра:** собственный оверлей поверх видео, ExoPlayer-рендер субтитров выключен.
  Верхний слой — язык A, нижний — язык B (по умолчанию A = en, B = ru).
  Размер, цвет, сдвиг по времени для каждого слоя — в настройках.
  В объёме этапа 3 сдвиг предусмотрен только для внешних субтитров; ограничение встроенных и соответствие UI исходному требованию отслеживаются в G-07. Сохранённые настройки пока не подключены к плееру.
- **Пульт:** OK — пауза/играть; ←/→ — ±10 с; ↓ — меню дорожек (аудио, субтитры A, B, сдвиг).
- Позиция просмотра сохраняется (продолжить с места).

### subs

Для каждого языка (A и B) порядок источников:
1. Встроенные в файл дорожки (извлекаются из Media3 track groups)
2. OpenSubtitles API (поиск по хэшу файла, затем по imdb id) — ключ в настройках
3. Перевод через `translate` из субтитров другого языка

Встроенные дорожки планируется получать через два текстовых рендерера Media3; одного перечисления track groups недостаточно. Эксперимент совместимости — задача 5 этапа 3. Контракт повторного поиска OpenSubtitles без хэша при отсутствии нужного языка уточняется в G-03.

Парсеры: SRT, WebVTT, ASS/SSA (только текст и тайминги, стили игнорируются).
Модель реализации: `SubtitleCue(startMs, endMs, text)` и `SubtitleTrack`; конец интервала исключительный, пересекающиеся cue объединяются.

### translate

ML Kit on-device. Модель языка скачивается при первом использовании (показать прогресс).
Переводит cue по одному, батчами, кэширует результат в Room по (hash файла, язык).
Перевод идёт в фоне, начиная с текущей позиции.

## Поток

Галерея (Кинопоиск / TMDB) → Карточка фильма → Список раздач → Экран загрузки (буфер) → Плеер

## Ошибки

| Ситуация | Поведение |
|---|---|
| Нет сидов / скорость < порога 30 с | Показать скорость, предложить другую раздачу |
| Кодек не поддерживается | Сообщение + предложить другую раздачу |
| Провайдер поиска недоступен | Результаты остальных + пометка |
| Нет сети / каталог недоступен | Экран ошибки с «Повторить» |
| Нет ключа / неверный ключ источника каталога | «Нужен ключ <источника>» / «Ключ <источника> неверный» + ссылка в настройки |
| Дневной лимит запросов исчерпан (Кинопоиск 402) | «Лимит запросов на сегодня исчерпан» + «Повторить» |
| Субтитры не найдены и перевод невозможен | Слой пустой, пометка в меню дорожек |

Реакция на отсутствие скорости после получения метаданных ещё не реализована (G-01); порог «низкой скорости» требует конкретизации. Понятное сообщение о кодеке — G-06. Причины отсутствия субтитров появятся с задачами 6–7 этапа 3.

## Настройки

- Источник каталога (Кинопоиск по умолчанию / TMDB), ключ Кинопоиска, TMDB API key, OpenSubtitles API key
- Включённые провайдеры
- Языки субтитров A и B, стиль слоёв
- Кэш: удалять после просмотра / хранить, лимит места

Ключи и пароли — в EncryptedSharedPreferences.

## Тестирование

- Юнит: парсеры SRT/VTT/ASS; провайдеры поиска на сохранённых ответах (фикстуры);
  парсер качества из названия; сведение/дедуп результатов; логика приоритетов кусков;
  выбор источника субтитров.
- Ручная проверка: совместимое устройство Android TV (APK через adb). Текущий APK имеет только ABI `armeabi-v7a`; для x86_64-эмулятора необходима отдельная совместимая конфигурация. Чеклисты и формат протокола — в [TESTING](../../TESTING.md).

## Этапы

Каждый этап — отдельный план и рабочий APK.

1. **Каталог:** каркас проекта, настройки, TMDB, галерея, карточка фильма.
2. **Стрим:** поиск (rutor, YTS, apibay — 3 провайдера), torrent-стример, плеер с выбором озвучки.
3. **Два субтитра:** встроенные + OpenSubtitles, парсеры, оверлей.
4. **Перевод:** ML Kit.
