# Android TV: галерея фильмов с торрент-стримом — дизайн

Дата: 2026-10-29

## Цель

Личное приложение для Android TV (ставится APK вручную, без Google Play).
Каталог фильмов с постерами → выбор фильма → поиск раздач → потоковый просмотр
торрента прямо на ТВ. Выбор озвучки и два субтитра одновременно (для изучения языка).

Своего медиасервера нет и не требуется. Всё работает на ТВ.

## Не входит

- Jellyfin / Plex (нет своей коллекции)
- Публикация в Google Play, мультипользовательность
- Сериалы (только фильмы; сериалы — возможный будущий этап)
- Облачный перевод (DeepL/Claude) — возможный будущий этап

## Стек

- Kotlin, Gradle (Kotlin DSL), minSdk 26, targetSdk — последний стабильный
- Jetpack Compose for TV (`androidx.tv:tv-material`)
- Media3 / ExoPlayer + ffmpeg-расширение (аудио DTS/TrueHD/AC3)
- libtorrent4j — торрент-движок
- ML Kit Translate (on-device)
- Room — кэш, история, настройки дорожек; DataStore — настройки
- Hilt — DI; Retrofit/OkHttp + kotlinx.serialization — сеть
- Coil — постеры

## Модули

Каждый модуль — пакет с одним публичным интерфейсом.

| Модуль | Задача | Интерфейс |
|---|---|---|
| `catalog` | TMDB: популярное, жанры, поиск, карточка фильма (название, оригинальное название, год, постер, описание, imdb id) | `CatalogRepository` |
| `search` | Поиск раздач по фильму, сведение результатов | `TorrentProvider`, `TorrentSearch` |
| `torrent` | Загрузка и стрим одного торрента | `TorrentStreamer` |
| `player` | ExoPlayer, выбор аудио, оверлей двух субтитров, управление пультом | `PlayerScreen` |
| `subs` | Получение и парсинг субтитров | `SubtitleSource`, `SubtitleParser` |
| `translate` | Перевод субтитров ML Kit | `SubtitleTranslator` |
| `settings` | Языки, ключи, логины, кэш | `SettingsRepository` |

### search

`TorrentProvider.search(movie: Movie): List<TorrentResult>`

`TorrentResult`: название, magnet/torrent-url, размер, сиды, личи, качество (2160p/1080p/720p, парсинг из названия), провайдер.

Провайдеры:
1. **RuTracker** — логин/пароль в настройках, парсинг HTML. Поиск по русскому названию + год.
2. **YTS** — публичный JSON API, поиск по imdb id.
3. **apibay (TPB)** — публичный JSON API, поиск по оригинальному названию + год.
4. **Prowlarr** — опционально: адрес + API-ключ в настройках, выключен по умолчанию.

`TorrentSearch` опрашивает включённые провайдеры параллельно (таймаут 15 с на каждый),
сводит, удаляет дубли по info-hash, сортирует по сидам. Упавший провайдер не ломает
выдачу — показывается пометка «RuTracker недоступен».

### torrent

- Добавить magnet/torrent, получить метаданные, выбрать самый большой видеофайл
  (или дать выбор, если видеофайлов несколько).
- Последовательная загрузка; приоритет первых и последних кусков (метаданные MP4/MKV).
- Локальный HTTP-сервер на `127.0.0.1:<порт>` с поддержкой Range. При запросе
  диапазона поднимает приоритет нужных кусков и ждёт их.
- Готов к воспроизведению: 5% файла или 20 МБ (что меньше) с начала + последние куски.
- Статус: скорость, сиды, буфер — показывается на экране загрузки и в плеере.
- После просмотра: удалить (по умолчанию) или хранить. Лимит кэша по месту (настройка).

### player

- ExoPlayer играет URL локального HTTP-сервера.
- **Озвучка:** список аудиодорожек (язык + label, напр. «Rus, MVO LostFilm»).
  Выбранная дорожка запоминается по языку.
- **Два субтитра:** собственный оверлей поверх видео, ExoPlayer-рендер субтитров выключен.
  Верхний слой — язык A, нижний — язык B (по умолчанию A = en, B = ru).
  Размер, цвет, сдвиг по времени для каждого слоя — в настройках.
- **Пульт:** OK — пауза/играть; ←/→ — ±10 с; ↓ — меню дорожек (аудио, субтитры A, B, сдвиг).
- Позиция просмотра сохраняется (продолжить с места).

### subs

Для каждого языка (A и B) порядок источников:
1. Встроенные в файл дорожки (извлекаются из Media3 track groups)
2. OpenSubtitles API (поиск по хэшу файла, затем по imdb id) — ключ в настройках
3. Перевод через `translate` из субтитров другого языка

Парсеры: SRT, WebVTT, ASS/SSA (только текст и тайминги, стили игнорируются).
Модель: `Cue(startMs, endMs, text)`.

### translate

ML Kit on-device. Модель языка скачивается при первом использовании (показать прогресс).
Переводит cue по одному, батчами, кэширует результат в Room по (hash файла, язык).
Перевод идёт в фоне, начиная с текущей позиции.

## Поток

Галерея (TMDB) → Карточка фильма → Список раздач → Экран загрузки (буфер) → Плеер

## Ошибки

| Ситуация | Поведение |
|---|---|
| Нет сидов / скорость < порога 30 с | Показать скорость, предложить другую раздачу |
| Кодек не поддерживается | Сообщение + предложить другую раздачу |
| Провайдер поиска недоступен | Результаты остальных + пометка |
| Нет сети / TMDB недоступен | Экран ошибки с «Повторить» |
| Субтитры не найдены и перевод невозможен | Слой пустой, пометка в меню дорожек |
| Неверный логин RuTracker | Пометка в выдаче, ссылка в настройки |

## Настройки

- TMDB API key, OpenSubtitles API key
- RuTracker логин/пароль
- Prowlarr: вкл/выкл, адрес, API-ключ
- Включённые провайдеры
- Языки субтитров A и B, стиль слоёв
- Кэш: удалять после просмотра / хранить, лимит места

Ключи и пароли — в EncryptedSharedPreferences.

## Тестирование

- Юнит: парсеры SRT/VTT/ASS; провайдеры поиска на сохранённых ответах (фикстуры);
  парсер качества из названия; сведение/дедуп результатов; логика приоритетов кусков;
  выбор источника субтитров.
- Ручная проверка: эмулятор Android TV + реальный ТВ (APK через adb).

## Этапы

Каждый этап — отдельный план и рабочий APK.

1. **Каталог:** каркас проекта, настройки, TMDB, галерея, карточка фильма.
2. **Стрим:** поиск (все 4 провайдера), torrent-стример, плеер с выбором озвучки.
3. **Два субтитра:** встроенные + OpenSubtitles, парсеры, оверлей.
4. **Перевод:** ML Kit.
