# Сериалы: дизайн

Дата: 2026-11-07. Статус: на подтверждении у пользователя.

## Зачем

Сейчас приложение показывает только фильмы; каталоги отсеивают сериалы ([спека](2026-10-29-android-tv-torrent-gallery-design.md), «сериалы — возможный будущий этап»). Пользователь хочет смотреть сериалы так же, как фильмы: открыть карточку, выбрать сезон и серию, смотреть, а потом продолжать с карточки «Продолжить просмотр».

Успех: на ТВ пультом можно найти сериал, выбрать серию, посмотреть её из раздачи сезона, перейти к следующей серии без нового выбора раздачи и продолжить просмотр с главной.

## Цели

- Сериалы в трёх каталогах: Кинопоиск, TMDB, PoiskKino.
- Главная с левым меню «Все / Фильмы / Сериалы».
- Поиск находит фильмы и сериалы вместе, с фильтром по типу.
- Карточка сериала: сезоны, серии, прогресс по сериям.
- Одна раздача сезона на все серии: файл серии выбирается автоматически.
- Автопереход к следующей серии.
- «Продолжить просмотр» для сериала.

## Не цели

- Расписание выхода новых серий, уведомления.
- Отметка «просмотрено» вручную, история по всем сериям сверх прогресса.
- Раздачи на весь сериал сразу (несколько сезонов): допускаются, если файл серии в них находится, но специально не ищутся и не ранжируются.
- Пропуск заставки.

## Антицели

- Поведение фильмов меняться не должно: всё, что работает и проверено для фильмов (поиск раздач, фильтр раздач, плеер, субтитры, продолжение), остаётся прежним.
- Не просить выбрать раздачу на каждую серию, если серия есть в уже выбранной раздаче.
- Не удалять раздачу сезона после одной серии.

## Решения пользователя

### Главная

- Слева узкая полоса с иконками «Все», «Фильмы», «Сериалы». Когда на полосу приходит фокус (← с первой карточки ряда), она раскрывается с подписями; при уходе фокуса сворачивается. Вариант A из макета.
- «Все»: ряды смешанные, фильмы и сериалы вместе. На карточке сериала метка «Сериал».
- «Фильмы» и «Сериалы»: ряды только этого типа.
- Шапка (логотип, «Поиск», «Настройки», часы) остаётся.

### Поиск

- Фильмы и сериалы в одной выдаче, метка «Сериал» на карточках сериалов.
- Фильтр «Все / Фильмы / Сериалы».

### Карточка сериала (вариант A из макета)

- Шапка как у фильма: постер, название, год, рейтинг, число сезонов, жанры, описание.
- Кнопка «▶ Продолжить SxxEyy», если сериал начат; иначе «▶ Смотреть S01E01».
- Ниже ряд вкладок «Сезон 1 · Сезон 2 · …», под ним горизонтальный ряд серий: кадр, «N. Название», длительность, полоска прогресса.
- Если кадра нет (Кинопоиск, часть PoiskKino), показывается заглушка с номером серии.

### Раздачи

- OK на серии открывает список раздач этого сезона (тот же экран раздач с фильтром).
- После выбора раздачи приложение само находит в ней файл нужной серии.
- Следующие серии берутся из той же раздачи без нового выбора.
- Если нужной серии в раздаче нет, снова открывается список раздач сезона.

### Конец серии

- Экран «Следующая серия через 10 с» с кнопками «Смотреть сейчас» и «Отмена».
- После последней серии сезона идёт первая серия следующего сезона, если она есть в той же раздаче; иначе список раздач следующего сезона (*вывод из правила «серии нет в раздаче»*).
- После последней серии сериала — текущий экран окончания («закончился»).

### Продолжить просмотр

- Одна карточка на сериал с подписью «SxxEyy».
- OK сразу включает эту серию с места остановки, без вопроса, как у фильмов.

### Удаление раздачи

Сейчас при `keepAfterPlayback = false` (по умолчанию) раздача стирается при каждом выходе из плеера. Для сериала при выключенном «оставлять» раздача сезона удерживается между выходами и удаляется при первом из событий:

- досмотрена последняя серия, которая есть в раздаче;
- включили что-то другое: фильм, другой сериал или другую раздачу этого сериала;
- не хватает места под новую раздачу (по общим правилам лимита).

При включённом «оставлять» всё как сейчас. Раздачу, которую сейчас смотрят, лимит не удаляет.

## Ограничения

- Kotlin, Compose for TV, пакет `dev.gamspi.videogallery`; сборка только через Docker; ABI `armeabi-v7a`.
- Требования [AGENTS.md](../../../AGENTS.md): сеть и файлы не на UI-потоке, `CancellationException` не поглощать, секреты только через `SecretStore`, UI проверяется пультом (фокус, Назад, восстановление выбранной карточки).
- В `stream` сохраняется владение сессией: переход к следующей серии не должен останавливать раздачу, если серия из той же раздачи.
- Идентификаторы каталогов — `Int`, и у TMDB id фильма и сериала пересекаются: тип (фильм/сериал) должен быть частью ключа везде, где хранится или передаётся id (маршруты, история, кэш, позиции).

## Что сейчас есть (для строителя)

- `CatalogRepository`: `popular`, `genres`, `byGenre`, `search`, `details` — только фильмы; `KinopoiskMapper.isFilm()` отсеивает сериалы.
- Главная: ряд «Популярное» и ряды жанров (`GalleryViewModel`).
- `TorrentProvider.search(movie: MovieDetails)` ищет по фильму.
- `StreamManager` уже умеет экран выбора файла (`StreamState.ChooseFile`) и `selectFile` в движке.
- История: `WatchEntry` по `movieId`, `PlaybackMeta` передаётся маршрутами releases → stream → player; позиции в `PlaybackStore` по ключу файла.
- Плеер: экран «Фильм закончился» с автовыходом через 5 с.
- OpenSubtitles API поддерживает поиск серий (parent IMDb, season, episode).

## Решения, оставленные строителю

Отмечено как мой выбор, пользователь мог не обсуждать детали:

- Ряды в «Фильмах» и «Сериалах»: «Популярные» и ряды жанров, как сейчас у фильмов. В «Все» — смешанные «Популярное» и жанры.
- Запрос раздач сезона: название и сезон в русском и оригинальном виде («Тьма сезон 2», «Dark S02»). Раздачи, где номер сезона не распознан или другой, уходят в конец списка, а не скрываются.
- Сопоставление файла с серией: по шаблонам `S02E05`, `2x05`, `E05`/`Серия 5` в имени файла; при единственном видеофайле без номера — не угадывать, считать серию ненайденной.
- Субтитры OpenSubtitles для серии: IMDb сериала + сезон + серия.
- Данные серий: TMDB — сезоны, серии, кадры, длительность; PoiskKino — сезоны и серии, кадры где есть; Кинопоиск (неофициальный API) — сезоны и названия серий без кадров. Что каталог не отдаёт, просто не показывается.
- Выбранная раздача запоминается на сезон. Если она содержит серию, OK на серии и «▶ Продолжить» включают её сразу; сменить раздачу можно кнопкой «Раздачи сезона» в шапке карточки. Если серии в ней нет, открывается список раздач.
- После досмотренной серии (≥90 %) карточка «Продолжить» показывает следующую серию с нуля; если её нет в раздаче, OK открывает раздачи её сезона. После последней серии сериала карточка пропадает.
- Ключ истории, позиций и сохранённой раздачи: источник каталога + тип + id. Записи другого каталога при переключении не показываются и не удаляются (*как сейчас решать для фильмов — проверить и выровнять*).
- В «Сериалы» идут все сериальные типы: мини-сериалы, ТВ-шоу, аниме и мультсериалы.
- Кнопка «Отмена» на экране следующей серии возвращает на карточку сериала с фокусом на следующей серии.
- Назад из плеера серии ведёт на карточку сериала, фокус на этой серии.
- Хранение прогресса серий и формат истории; миграция существующей истории фильмов без потерь.

## Проверка

- Unit-тесты: сопоставление файлов серий, ранжирование раздач по сезону, мапперы трёх каталогов, история и продолжение для сериала.
- ТВ: сценарий «главная → Сериалы → карточка → серия → раздача → просмотр → следующая серия → выход → Продолжить» на каждом каталоге, запись в протокол приёмки.
