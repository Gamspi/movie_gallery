# Плеер: меню субтитров по слоям и запоминание выбора

Дата: 2026-11-11. **Статус: код и unit-тесты в рабочем дереве, приёмка на ТВ не выполнена.** Решения пользователя приняты в диалоге 2026-11-11.

## Решения

- **Навигация.** Раздел «Субтитры» показывает две строки в стиле списка разделов (со стрелкой ›): «Слой A (ru): <текущий вариант>» и «Слой B (en): <текущий вариант>». OK открывает экран слоя: заголовок «Слой A (ru)», регулятор размера (←/→ как раньше), затем варианты `layerOptions` с отметкой текущего и неактивными пояснениями. Фокус — на текущем варианте или «Выкл».
- **Назад.** С экрана слоя — в «Субтитры» с фокусом на строке этого слоя; из «Субтитры» — в список разделов с фокусом на «Субтитры»; из списка разделов — закрыть меню. Вложенность — новое состояние фокуса `PlayerFocus.MenuLayer` и команды `OpenMenuLayer`/`BackToLayers` в `handleKey`; корневой обработчик по-прежнему отдаёт все клавиши, кроме Назад, фокусу меню. Выбор варианта оставляет экран слоя открытым.
- **Запоминание.** Ручной выбор каждого слоя сохраняется на диск (`PlaybackStore`, SharedPreferences `playback`) для тайтла: фильм — по тайтлу, сериал — на весь сериал (действует и для следующей серии). Ключ: `source:kind:movieId`, иначе `imdb:kind:imdb`, иначе ключ воспроизведения (одно видео).
- **Описание выбора.** Хранится описание, не объект: Выкл; встроенная (язык, метка); OpenSubtitles (язык, fileId, релиз); перевод (слой-источник, язык источника). Авто (None) не хранится; сохраняются только ручные выборы (`select`).
- **Восстановление** вместо автовыбора: Выкл → Выкл; встроенная → та же язык+метка, иначе тот же язык, иначе автовыбор; OpenSubtitles → тот же fileId, иначе первый результат того же языка, иначе автовыбор (после прихода результатов поиска слой переключается на сохранённый); перевод → тот же вариант, когда источник готов, иначе автовыбор. Восстановленный слой больше не меняется автовыбором. Правило конфликта (два слоя не делят одну встроенную группу) сохраняется.
- Аудио и «Прочее» не меняются.
