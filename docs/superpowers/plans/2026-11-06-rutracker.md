# Источник rutracker: план

Дата: 2026-11-06. **Статус: реализовано, приёмка частичная — [протокол](../../verification/2026-11-06-proxy-rutracker.md).** Продолжение [прокси через Cloudflare](2026-11-06-cloudflare-proxy.md). Решения пользователя приняты в диалоге 2026-11-06.

## Факты

- `rutracker.org` с ТВ напрямую закрыт провайдером; доступен через воркер (хост в белом списке воркера и `ProxyInterceptor`).
- Поиск (`forum/tracker.php`) только после входа. Страницы в windows-1251.
- В выдаче поиска нет хеша; магнет есть на странице раздачи (`viewtopic.php?t=ID`, ссылка `magnet:`). Магнет rutracker содержит HTTP-ретрекер — нам подходит (UDP режет провайдер).
- `dl.php?t=ID` требует cookie входа — `.torrent` не используем, только магнет.
- После неудачных попыток вход может просить капчу.

## Решения

- **Хеш при выборе.** Поиск — один запрос; результат rutracker без хеша, с адресом раздачи. По OK приложение открывает страницу раздачи, берёт магнет и идёт дальше как обычно. Пока идёт запрос — индикатор на карточке раздачи; при ошибке — сообщение «Не удалось открыть раздачу», экран остаётся.
- **Только фильмы.** Запрос «название год», при пустом — «оригинальное название год» (как rutor). Отсев по разделу (строки из разделов кино/HD/UHD/DVD; сериалы, мультсериалы, музыка, игры, трейлеры — нет) и по году в названии.
- **Вход.** `POST forum/login.php` (windows-1251: `login_username`, `login_password`, `login=вход`), без следования редиректу; cookie `bb_session` хранится в памяти провайдера и подставляется заголовком `Cookie` вручную (`CookieJar` OkHttp видит адрес воркера, поэтому не используется). Если поиск вернул форму входа — один повторный вход. Логин и пароль — из `SecretStore` (`rutracker_username`, `rutracker_password`, с подстановкой из `.env`).
- **Ошибки входа** не ломают поиск остальных трекеров. На экране раздач — пояснение для rutracker: капча → «rutracker просит капчу — войди один раз в браузере»; неверный логин/пароль → «rutracker: неверный логин или пароль»; нет логина → «rutracker: укажи логин и пароль в настройках».
- **Настройки.** Раздел «Трекеры»: rutracker (адрес, по умолчанию `https://rutracker.org`, переключатель), поля «Логин rutracker» и «Пароль rutracker» (маскированный). По умолчанию включён, если логин есть (на ТВ или в `.env`).
- Секреты не логируются и не попадают в тесты (фикстуры с вымышленными значениями).

## Ограничения

Docker-сборка, `armeabi-v7a`, без сети/файлов на UI-потоке, не глотать `CancellationException`, отмена отменяет HTTP-запрос. Разметка rutracker не гарантирована: парсер терпим к отсутствующим полям, живая проверка — на ТВ.
