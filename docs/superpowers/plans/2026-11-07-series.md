# Сериалы — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Статус 2026-11-07:** задачи 1–11 реализованы на ветке `series` с ревью каждой задачи и финальным ревью ветки; задача 12 — приёмка на ТВ частичная ([протокол](../../verification/2026-11-07-series.md)). Чекбоксы шагов ниже исторические.

**Goal:** сериалы в трёх каталогах: главная с левым меню «Все / Фильмы / Сериалы», поиск с фильтром, карточка с сезонами и сериями, одна раздача на сезон, автопереход к следующей серии, «Продолжить» по серии.

**Architecture:** тип `MediaKind` проходит через модель каталога, маршруты, историю и позиции. Новый `SeriesStore` хранит выбранную раздачу сезона, карту «серия → файл» и прогресс серий. `StreamManager` получает `EpisodeRef`: сам выбирает файл серии и удерживает раздачу в `TorrentCacheStore` между выходами. Что делать после серии, решает чистая функция `afterEpisode`.

**Tech Stack:** Kotlin, Compose for TV, Hilt, Retrofit + kotlinx.serialization, libtorrent4j, Media3. Сборка и тесты только через Docker.

**Spec:** [docs/superpowers/specs/2026-11-07-series-design.md](../specs/2026-11-07-series-design.md)

## Global Constraints

- Пакет `dev.gamspi.videogallery`; ABI `armeabi-v7a`; сборка `./scripts/gradle-docker.ps1 ./gradlew testDebugUnitTest assembleRelease`, результаты сверять по XML в `app/build/test-results/testDebugUnitTest/`.
- Сеть и файлы не на UI-потоке. `CancellationException` не поглощать. Отмена отменяет HTTP-запрос.
- Секреты только через `SecretStore`. В тестах, логах и доках ключей нет.
- Пользовательские строки на русском, комментарии кратко на английском, файлы UTF-8 без BOM.
- Поведение фильмов не меняется. Существующие тесты остаются зелёными без правки ожиданий, кроме сигнатур с новыми параметрами по умолчанию.
- Тип входит в ключ везде, где хранится или передаётся id: маршруты, история, `SeriesStore`, ключ кэша каталога.
- Метка на карточке — «Сериал». Тексты экрана следующей серии: «Следующая серия через N с», «Смотреть сейчас», «Отмена». Кнопки карточки: «▶ Продолжить SxxEyy», «▶ Смотреть S01E01», «Раздачи сезона».
- Раздача сезона при `keepAfterPlayback = false` удерживается между выходами. Удаляется, когда досмотрена последняя серия, которая в ней есть; когда включили что-то другое (фильм, другой сериал, другую раздачу); когда не хватает места по лимиту. Активную раздачу лимит не трогает.
- Коммиты только по просьбе пользователя. Шаг «Commit» выполняется, если пользователь разрешил коммиты для этой работы.

## Review Focus

- Сезонный пак с вложенными папками, `sample`-файлами и допами: серия находится по номеру, `sample` и файлы меньше 50 МБ игнорируются (тест в задаче 5).
- Пак на несколько сезонов (`S01-S03`, `1-3 сезон`): следующий сезон берётся из той же раздачи без выбора (тесты в задачах 5 и 9).
- В раздаче нет нужной серии: `StreamState.EpisodeMissing`, экран возвращается к списку раздач сезона, без падения и без «Видеофайлы не найдены» (тест в задаче 7).
- Старая история в JSON без новых полей читается: фильмы видны в «Продолжить» и открываются как раньше (тест в задаче 6).
- У TMDB одинаковый id фильма и сериала: записи истории и `SeriesStore` не перетирают друг друга (тест в задаче 6).
