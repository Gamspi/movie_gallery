# UI polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Янтарная тема, аккуратный главный экран без обрезки и перекрытий, плавная прокрутка, скелетоны и «кот с попкорном» на загрузках, настройки по разделам, кнопки ⏯/⚙ и меню с разделами в плеере, новая иконка приложения.

**Architecture:** Общие токены темы и компоненты в `ui/theme` и `ui/components` (иконки, скелетоны, лоадер, кнопка-пилюля). Экраны переводятся на них по одному. Логика клавиш плеера остаётся чистой функцией (`handleKey`) с явным состоянием фокуса и тестами по таблице из спеки. Настройки разбиваются на маршруты `settings` и `settings/{section}`, автосохранение при «Назад».

**Tech Stack:** Kotlin, Jetpack Compose, `androidx.tv:tv-material`, `compose-material3` (`OutlinedTextField`), Coil 3, Hilt, Navigation Compose, JUnit 4.

**Spec:** `docs/superpowers/specs/2026-11-03-ui-polish-design.md`

## Global Constraints

- Сборка и тесты только через Docker: `./scripts/gradle-docker.ps1 ./gradlew testDebugUnitTest assembleDebug`; проверять XML в `app/build/test-results/testDebugUnitTest/`.
- ABI `armeabi-v7a` не меняется. Новых тяжёлых зависимостей нет (без Lottie); иконки — свои `ImageVector`.
- Пользовательские строки на русском, комментарии к коду кратко на английском, UTF-8 без BOM.
- Ключи только через `SecretStore`; маскирование полей ключей/пароля сохраняется; секреты не попадают в логи и протоколы.
- Корневой обработчик плеера не перехватывает навигацию открытого меню; «Назад» не выходит из просмотра при открытом меню или фокусе на кнопках.
- Сохраняются: первичный фокус на первой карточке, возврат фокуса на прежнюю карточку после «Назад», позиция прокрутки ряда, ключи `PlaybackStore`, поведение `stream`.
- Акцент: рамка фокуса ≥ 3:1 к фону; тёмный текст на янтарной заливке ≥ 4.5:1. Фон и поверхности тёмные, как сейчас.
- Текущие строки состояния (пиры, скорость, буфер %, статус) не пропадают ни на одном экране.

## Review Focus

1. Возврат с «Деталей» на главный экран после смены шапки и `contentPadding`: фокус встаёт на прежнюю карточку, а не на иконку поиска (тест: ручной сценарий в задаче 9, плюс `LaunchedEffect`-логика не меняется в задаче 5).
2. Повтор «Вниз»/«Вверх» с удержанием в плеере: повтор клавиши не должен прыгать между состояниями таблицы (тест `downRepeatDoesNotOpenMenu` в задаче 7).
3. «Назад» из раздела настроек при ошибке записи: остаёмся в разделе, ввод цел (тест `saveCatalogFailureReturnsFalse` в задаче 6).
4. Кот-лоадер не крутится, когда экран ушёл с переднего плана, и не грузит UI-поток при буферизации поверх видео (проверка в задаче 9 через `gfxinfo` в плеере).
5. Экран ошибки каталога «Открыть настройки» ведёт сразу в раздел «Каталог» (тест маршрута `settingsRoute(SettingsSection.Catalog) == "settings/catalog"` в задаче 6).
