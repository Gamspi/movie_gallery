## 1. Чистые правила подбора

- [x] Исходные «Для вас»: до 10 тайтлов с my_rating ≥ 8 (у сериала — сохранённое округлённое среднее по сезонам); если их меньше трёх — дополнение watched/watching без оценки до трёх. Оценённые ниже 8 не используются.
- [x] Исходные рядов главной: два последних по правке тайтла с оценкой ≥ 8; только при их полном отсутствии — последние watched.
- [x] Исключение всех живых записей списка независимо от статуса, включая dismissed/dropped; метки удаления не исключают и не служат исходными.
- [x] Дедупликация тип+id, один голос от исходного тайтла; порядок — число исходных, затем рейтинг каталога. Unit-тесты правил, границ, вставки рядов и разбиения экрана.

## 2. Каталоги и запросы

- [x] TMDB `{movie|tv}/{id}/recommendations`, при пустом ответе `similar`; PoiskKino `similarMovies` из деталей `v1.5/movie/{id}`; Кинопоиск `films/{id}/similars` + детали не более 10 кандидатов (тип и рейтинг есть только там, без сезонов и прокатов).
- [x] Совпадение источника — прямой catalog_id; чужой каталог — поиск по imdb_id (TMDB `find`, PoiskKino `externalId.imdb`, Кинопоиск `films?imdbId=`), предпочтение того же типа; чужой без IMDb пропускается.
- [x] Кэш сопоставлений: в памяти и на диске (`imdb-matches.json`: только id и время; найденные — 90 дней, промахи — 7). Ошибки запроса не кэшируются.
- [x] Лимиты: не больше 10 исходных («Для вас») и 2 (главная), 3 параллельных запроса, не больше 20 сетевых сопоставлений исключений за загрузку; ещё не сопоставленные чужие тайтлы исключаются по названию, типу и году. Ответы «похожих» — общий HTTP-кэш (час, детали — сутки) и память загрузчика.
- [x] Тесты запросов, парсинга, HTTP-кэша и ошибок трёх репозиториев; тесты загрузчика: кэши, бюджет, отмена, ограничение параллельности, ошибки.

## 3. Главная и экран

- [x] Пункт «Для вас» (звезда) после «К просмотру»/«Просмотренные», те же карточки, бейджи и меню долгого OK; ряды по 20 карточек, до 60; пустая подсказка «Оцените пару фильмов — здесь появятся похожие». Полный отказ каталога — экран ошибки с «Повторить».
- [x] До двух рядов «Похожие на „X“» только во «Все», после «Скоро», перед жанрами; ряды каталога показываются сразу, похожие — после загрузки; сбой ряда его скрывает.
- [x] Обновление по изменениям живых тайтлов списка/каталога; карточка открывается в текущем каталоге. Ключи рядов каталога не сдвигаются вставкой; при исчезновении фокусной карточки после закрытия меню фокус переходит к соседней, иначе на меню.

## Границы этапа

Живые запросы с ключами не выполнялись: фильтр PoiskKino `externalId.imdb` для v1.5 и формат `similarMovies` взяты из документации kinopoisk.dev и проверяются на ТВ. Запасное исключение по названию может пропустить тайтл с другим переводом названия до его сопоставления по IMDb. Ряды «Для вас» пересчитываются при каждой правке живого тайтла, но сетевые запросы повторяются только после истечения кэшей.
