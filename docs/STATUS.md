## Отличия от целевой спецификации

- FFmpeg добавлен в G-06; проверен на телефоне, приёмка ТВ открыта. Хранение торрент-кэша и лимит добавлены в G-05; нативная приёмка хранения остаётся открытой.
- Стример управляет дедлайнами кусков и упреждающей загрузкой, а не флагом последовательной загрузки; это решение плана 2в.
- Вместо Room/DataStore сейчас используются SharedPreferences: секреты и настройки через `SecretStore`, позиция и озвучка через `PlaybackStore`.
- Сдвиг поддерживается только для внешних субтитров. Решение 2026-11-02 (G-07): встроенные остаются без сдвига; настройки и меню явно это указывают.
- G-10 (2026-11-02): при выборе раздачи rutor/YTS приложение качает `.torrent` по HTTP (10 с, 5 МБ, ≤5 редиректов), сверяет v1-хэш и стартует движок из файла; любой сбой — тихо magnet. Файл `torrents/<hash>/meta.torrent` живёт и удаляется вместе с раздачей. 507 unit-тестов; на ТВ `.torrent` YTS и rutor используется ([протокол](verification/2026-11-02-torrent-file.md)); повтор с сохранённым файлом и явное попадание трекеров файла на ТВ не проверены.
- Дополнительные дефекты, неоднозначности и критерии исправления: [BACKLOG](BACKLOG.md).
