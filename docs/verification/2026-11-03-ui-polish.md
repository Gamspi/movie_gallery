- Относительно исходной debug-сборки медиана кадра ряда: 450 → 34 мс (≈ 13×); доля рывков 100 % → 38 %. Нагрузка в замере — очередь из 40 нажатий подряд, жёстче удержания кнопки.
- `adb install` не запускает компиляцию профиля сразу; в `TESTING.md` добавлена команда `cmd package compile -m speed-profile`.
- Smoke (исполнитель 5b): каталог, детали, поиск раздач, открытие торрента, ≈ 45 с воспроизведения с субтитрами, настройки — без падений; `logcat -b crash` пуст.
