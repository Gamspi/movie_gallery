# Приёмка UI polish (2026-11-03)

## До изменений: замер плавности

- Код: `7141f3a` (до задач плана) плюс временная правка только для замера: кнопка «Настройки» на экране ошибки (без неё нельзя было сменить источник каталога; на главный экран с контентом не влияет).
- Устройство: Xiaomi MiTV-MOEU1, `armeabi-v7a`, API 34, Wi-Fi, ByeDPI-VPN, источник каталога PoiskKino.
- Метод: `dumpsys gfxinfo <pkg> reset`, затем одна команда `input keyevent` с N кодами подряд (очередь нажатий, жёстче удержания), затем `dumpsys gfxinfo`.

Наблюдения:
- GPU укладывается (6–13 мс); все рывки — «Slow UI thread»: узкое место в композиции/раскладке на главном потоке, а не в отрисовке или загрузке картинок (`Slow bitmap uploads` = 0).
- Отладочная сборка (debuggable) примерно в 4 раза медленнее на UI-потоке; ежедневно на ТВ стоит именно она.
- Поиск не замерялся: ввод текста через adb в поле поиска на ТВ не делался; замер поиска — в разделе «После» вручную пультом.
- Визуально (скриншот): карточка в фокусе обрезана слева отступом экрана и перекрывает заголовок ряда и подпись.
