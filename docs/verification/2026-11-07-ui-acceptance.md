## Найдено и исправлено

- Секрет открывался при одном лишь фокусе на поле (`3c79789`): маска теперь зависит от режима ввода и возвращается при закрытии клавиатуры (`c05b641`).
- Хэш-совпадения OpenSubtitles с чужим IMDb выбирались первыми: отбрасываются, если IMDb фильма и результата известны и различаются (`1a67880`).
- Прогресс около 1 % не был виден на карточке: минимальная заливка 4 % (`1a67880`).

## Не проверено

- Замер `gfxinfo` в плеере при буферизации; полная таблица клавиш плеера.
- `.torrent` rutor через прокси отдельно; сообщение rutracker о неверном пароле.

## Ограничения

- При активном ByeDPI без исключения приложения торрент не получает метаданные; это поведение среды, известное по ТВ.
- Повторный запуск того же фильма качает заново: по умолчанию сохранённые раздачи удаляются после просмотра.
- Видеослой не попадает в `screencap`, кадр виден только при открытой панели или во время паузы.
