## Покрытие тестов

- Правила: до 10 исходных с оценкой ≥ 8, добор до трёх из watched/watching без оценки, низкие оценки не используются, среднее сезонов сериала, ряды главной (две последние высокие оценки, иначе watched), удалённые метки и не-тайтлы.
- Слияние: голос одного исходного, тип+id, порядок по числу исходных и рейтингу; вставка рядов после «Скоро» перед жанрами; разбиение экрана по 20 до 60; имя исходного.
- Загрузчик: прямой catalog_id, IMDb чужого каталога, пропуск без IMDb, исключение dismissed/dropped, кэш памяти и диска (разделение по каталогу, сроки промахов/находок, повреждённый файл), не больше 20 сопоставлений исключений за загрузку, запасное исключение по названию/типу/году, ограничение 3 запросов, отмена, отказ одного ряда, ошибка при отказе всех.
- TMDB: путь recommendations и language, переход на similar при пустом ответе, find с предпочтением типа, 401.
- PoiskKino: similarMovies из деталей, повтор из HTTP-кэша, фильтр `externalId.imdb` и проверка id, нет ключа без запроса, 403 → лимит.
- Кинопоиск: similars + не больше 10 деталей без сезонов/прокатов, пропуск сломанной детали, `films?imdbId=` с предпочтением типа, нет ключа без запроса.
