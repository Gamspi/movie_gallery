# Эксперимент двух встроенных дорожек

Дата: 2026-10-31. База: `b5f4833`, локальные изменения задачи 5 этапа 3.

## Реализация

- `DualTextRenderersFactory` создаёт два одинаковых `TextRenderer` с отдельными выходами cue.
- `DualTextTrackSelector` принимает индексы полного списка групп `Tracks`, а не локальные индексы renderer. Media3 назначает каждую группу одному renderer; второй получает выбранную группу из общего списка.
- Одна группа не назначается двум слоям: `ProgressiveMediaPeriod` запрещает два потока одной группы. Выбор слоя B должен учитывать уже занятую группу A.
- Выбор слоя B нельзя восстанавливать по `Tracks.isSelected`: для группы, mapped к первому renderer, это не отражает выбор второго. Источником выбора должны служить слоты приложения.
- Основной `PlayerScreen` пока не изменён. Эксперимент использует отдельную Activity только в debug-сборке.

## Тестовый файл

Синтетический `build/dual-text-probe/subs2.mkv`: 180 секунд, H.264 640×360, 24 fps, две SubRip-дорожки `eng` и `rus`, без аудио. 20 cue, начало каждые 9 секунд, длительность 6 секунд; между репликами есть 3 секунды пустоты. В английском слое `English cue N`, в русском — `Русский текст N`. Файл и промежуточные SRT находятся в игнорируемом `build/`.

Для повторного создания файла и обоих SRT из корня репозитория выполните `./scripts/make-dual-text-fixture.ps1`. Мультиплексирование выполнено локальным Docker-образом FFmpeg 9.0.2:

```powershell
docker run --rm -v F:/projects/movie_gallery/build/dual-text-probe:/w --entrypoint ffmpeg linuxserver/ffmpeg:latest -hide_banner -loglevel error -y -f lavfi -i color=c=0x203040:s=640x360:r=24:d=180 -i /w/en.srt -i /w/ru.srt -map 0:v -map 1 -map 2 -c:v libx264 -preset ultrafast -pix_fmt yuv420p -c:s srt -metadata:s:s:0 language=eng -metadata:s:s:1 language=rus /w/subs2.mkv
```

## Запуск debug-пробы

Сначала установите debug APK на явно выбранное устройство. Устройство должно поддерживать ABI сборки (`armeabi-v7a`). Укажите HTTP URL файла, доступный именно этому устройству:

```text
adb -s <device> shell am start -n dev.gamspi.videogallery/.player.DualTextProbeActivity --es url <fixture-url>
adb -s <device> logcat -d -s DualTextProbe:I
adb -s <device> shell am start -n dev.gamspi.videogallery/.player.DualTextProbeActivity --es command pause
adb -s <device> shell am start -n dev.gamspi.videogallery/.player.DualTextProbeActivity --el seekMs 10000
adb -s <device> shell am start -n dev.gamspi.videogallery/.player.DualTextProbeActivity --es command play
```

Повторная передача `url` сбрасывает слоты и текст перед загрузкой нового файла. Логи пробы содержат текст синтетических cue; используйте её для тестовых файлов без приватных субтитров. Закрытие Activity освобождает плеер, уход в фон ставит его на паузу. Проба не проверяет меню и ViewModel основного плеера.
