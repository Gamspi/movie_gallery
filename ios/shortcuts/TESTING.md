# Тесты на iPhone

Ручной чек-лист всех шорткатов `ios/shortcuts/` на живых данных: настоящий poiskkino, настоящий Data Jar. Формат: действие → ожидаемый результат. Тексты меню и уведомлений — дословно из `shortcut.xml`.

Movie Add уже проверен — для него только регрессия.

## Подготовка

- [ ] На Mac: `ios/shortcuts/build.sh` → импортировать 9 шорткатов (Movie Sync, Movie Lookup, Movie Card, Movie Add, Movie Rate, Movie Recommend, Movie Tonight, Movie Stats, Movies). Старые Movie Seasons и его автоматизацию в «Командах» удалить. Имена — точно как в [README](README.md#шорткаты): Run Shortcut ищет по имени.
- [ ] Data Jar: есть `movies.settings` по [data.md](data.md#moviessettings), ключ API вписан, `ai_enabled` = `true`. Для разделов 1–4 синхронизация выключена (`sync_enabled` нет или `false`) — проверяется отдельно в [разделе «Синхронизация»](#синхронизация-movie-sync).
- [ ] Записать на бумажку текущий ключ API (для теста 401 его придётся испортить и вернуть).
- [ ] В базе ≥ 5 тайтлов, из них ≥ 3 с оценкой (иначе «Мой список» и «Разбор вкуса» не показывают вкус), хотя бы один сериал со статусом «Смотрю»/«Смотрел» и `kinopoisk_id`.
- [ ] (необязательно, быстро) Пустая/маленькая база → временный [Movie Seed](seed/README.md) (`build.sh seed`) → «Наполнить»: 18 тестовых записей без запросов poiskkino, живые не трогает.
- [ ] Записывать ключи тестовых записей — их нужно удалить в [Уборке](#уборка).

### Расход запросов poiskkino

Демо-ключ — 200 запросов/сутки. Примерно: Add/Lookup ≈ 2 (до 4), открыть несохранённую карточку 1–2, «Обновить данные» 1–2, «Похожие» 1. Rate, Stats, Recommend (до открытия карточки) — 0. Movie Sync в poiskkino не ходит.

Порядок ниже экономит запросы: сначала то, что стоит 0, потом то, что тратит. Ошибочный ключ — в конце. Кончился лимит (уведомление `poiskkino: <код> <сообщение>` при правильном ключе) — продолжать завтра.

## 1. Без запросов (0 poiskkino)

### Movie Rate

- [ ] Запуск → меню «Показать»: Несмотренные / Смотрю / Посмотренные / Бросил / Скрытые / Все / Синхронизировать.
- [ ] «Все» → список без скрытых; у оценённых ` ★ N`, у «Смотрю» ` ▶`; заголовок «<фильтр>: N».
- [ ] Каждый фильтр → только тайтлы своего статуса.
- [ ] Фильтр без записей (обычно «Бросил» или «Скрытые») → уведомление «Пусто», снова меню «Показать».
- [ ] Первый пункт списка — «← К фильтрам» → снова меню «Показать»; другой фильтр → его список. Счётчик в заголовке «<фильтр>: N» — без этого пункта.
- [ ] Выбрать тайтл → карточка; «Назад» → снова список (база перечитана).
- [ ] Cancel в списке и в меню «Показать» → шорткат завершился без ошибки.
- [ ] Два тайтла с одинаковой меткой (ремейк того же года) → вторая метка с ` · key`. (Если таких нет — пропустить.)

### Movie Card (сохранённая, без сети)

Открывать через Rate.

- [ ] Текст карточки: названия, `год · тип · N мин · возраст+`, жанры, `IMDb x · КП y · мой балл z`, Статус, Теги, Заметка, описание; пустые строки не показываются.
- [ ] Меню: Оценить · Статус · (сериал: Статус сериала · Уведомления: вкл/выкл) · Теги · Заметка · Спросить ИИ · Кинопоиск · IMDb · Трейлер · Постер · Похожие · Поделиться · Обновить данные · В календарь · Удалить · Назад.
- [ ] Оценить → «Оценка 1–10» → ввести 11 → уведомление «1–10», ничего не сохранено.
- [ ] Оценить → 7 → «Пара слов? (можно пусто)» → текст → карточка: `мой балл 7`, Статус «Смотрел», заметка дописана через ` · ` к старой.
- [ ] Оценить → 9 → после отзыва «Показать похожие?» → «Нет» → снова карточка. («Да» — в разделе 2.)
- [ ] Статус → Не смотрел / Смотрю / Смотрел / Бросил / Не предлагать → метка в карточке сменилась.
- [ ] Статус → «Смотрел» у тайтла без оценки → «Оценить сейчас?» → «Да» → поток оценки; «Нет» → без оценки.
- [ ] Теги → prompt «Теги (сейчас: …)» → выбрать 2 → в карточке оба. Выбрать один → строка «Теги: <тег>».
- [ ] Теги → ничего не выбрать (Done) → теги удалены, строки «Теги» нет.
- [ ] Заметка → поле с текущей заметкой → изменить → обновилось.
- [ ] Кинопоиск / IMDb / Трейлер → встроенный Safari; Done → снова карточка.
- [ ] Кинопоиск у `ai-`записи → «Нет id Кинопоиска»; IMDb без `imdb_id` → «Нет IMDb id».
- [ ] Постер → картинка в Quick Look; у записи без `poster_url` → «Нет постера».
- [ ] Поделиться → лист Share с текстом и ссылками.
- [ ] В календарь у старого тайтла → «Премьера уже была»; без `premiere_date` → «Нет даты премьеры».
- [ ] Удалить → «Удалить <title_ru>?» → «Нет» → карточка; (сам «Да» — в Уборке).

### Movie Stats

- [ ] Запуск → Quick Look: «Всего: N», «Статусы: …», «Типы: …», «Оценено: n, средняя x», любимые жанры (до 5, `Жанр — 7.9 (14)`), посмотрено по годам, топ-5 `★N …`.
- [ ] Числа в «Статусы» совпадают с количествами в Rate по фильтрам.
- [ ] Закрыть Quick Look → «Дальше?»: Разбор вкуса (ИИ) / Готово. «Готово» → конец.
- [ ] «Разбор вкуса (ИИ)» → чат на русском (4–6 предложений + 3 направления); можно задать ещё вопрос.
- [ ] (при < 3 оценок) «Разбор вкуса» → «Мало оценок». Пустая база → «База пуста» — не проверять на живой базе.

### Movie Recommend (до открытия карточки)

- [ ] Запуск → «Что смотрим?»: Мой список (по вкусу) / Случайный / По настроению (ИИ) / Новое (ИИ) / Выход. «Выход» → конец.
- [ ] Любой режим → «Фильтры»: Без фильтров / Настроить / ← Назад. «← Назад» → меню.
- [ ] «Мой список» → «Без фильтров» → `top_n` (3) тайтлов `— <прогноз>`, + «← Назад».
- [ ] «Мой список» → «Настроить»: «Тип (ничего = любой)» → «Жанры (ничего = любой)» → «Длительность» (Любая / ≤ 90 мин / ≤ 120 мин / ≤ 150 мин) → «Тег» (+ «Любой») → список соблюдает фильтры.
- [ ] Фильтр, под который ничего нет (тип «Аниме» + ≤ 90 мин) → «Ничего не подходит» → снова «Фильтры».
- [ ] «По настроению» → «Какое настроение?» (ввести по-русски) → 0–2 уточнения: вопрос и варианты по-русски (перевод) + «Своё…» → список до 3 тайтлов из своего списка с причиной ` · …` по-русски + «↻ Не то…» + «← Назад». Нет ошибки «The model cannot provide a response…».
- [ ] Уточнение → «Своё…» → ответ по-русски → подбор работает.
- [ ] Авиарежим → «По настроению» → перевод работает (русский и английский скачаны в «Перевод»; иначе ошибка Translate — норма).
- [ ] «↻ Не то…» → «Что не так? (слишком старое, хочу смешнее…)» (по-русски) → новый список без прежних тайтлов, настроение не спрашивается заново.
- [ ] «Новое» → 5 тайтлов не из базы, с причиной; ни одного уже имеющегося.
- [ ] Cancel в любом списке/вводе → шорткат завершился (ограничение Shortcuts — это норма).

## 2. С запросами

### Movie Add (регрессия, ~2–4)

- [ ] «Что добавить?» → новый тайтл → превью → «Да, это он» → «Уже смотрел?» → «Нет» → «Теги?» → «Пропустить» → «Добавлено: <title_ru> (<год>) · Не смотрел».
- [ ] Тот же тайтл ещё раз → «Уже в списке: …» → открылась карточка (0 доп. запросов, кроме Lookup).
- [ ] Будущая премьера → без «Уже смотрел?» → «Добавить премьеру в Календарь?» → «Да» → событие «Премьера: <title_ru>»; повтор через карточку «В календарь» → «Премьера уже в Календаре».

### Movie Lookup (через Add, без сохранения — в превью «Отмена»)

- [ ] Однозначный запрос («Severance») → сразу превью, без «Что именно?».
- [ ] Неоднозначный («дюна») → «Что именно?»: до 3 вариантов `title_ru / title_en (год, тип)` + «Нет в списке».
- [ ] С опечаткой («разделенее сериал») → правильный тайтл.
- [ ] Сериал vs фильм с тем же названием («Фарго» фильм / сериал) → тип в превью совпадает с выбранным.
- [ ] Свежий тайтл, которого ИИ не знает → «Нет в списке» → поиск по сырому вводу → нашёлся.
- [ ] Выдуманное название → «Нет в списке» → «Не найдено. Сохранить как есть?» → «Нет» → Add молча закончился (пустой результат обработан, без ошибки).
- [ ] Выдуманное → «Да» → «Год?» (можно пусто) → «Тип?» → превью с «(нет в poiskkino)». Сохранить → запись с ключом `ai-…` (кириллица → `ai-<yyyyMMddHHmm>[-год]`). Записать ключ для уборки.
- [ ] Отмена в «Что именно?» → Add закончился без ошибки.
- [ ] Тайтл без рейтинга IMDb/КП → в превью нет `IMDb`/`КП`, сохранение без ошибки, в карточке нет строки рейтингов (или только имеющийся).
- [ ] Тайтл без даты премьеры → «Уже смотрел?» показывается, календарь не предлагается.

### Movie Card (несохранённая и сеть)

- [ ] Оценить тайтл на 8+ → «Показать похожие?» → «Да» → список «Похожие» (`— КП y`) + «← Назад» (1 запрос).
- [ ] Похожие у `ai-`записи (нет `kinopoisk_id`) → список от ИИ (0 запросов).
- [ ] В списке похожих нет уже посмотренных/брошенных/скрытых.
- [ ] Выбрать похожий → несохранённая карточка (ленивый Lookup, 1–2 запроса): меню Добавить в список · Смотрел + оценка · Не предлагать · Спросить ИИ · Кинопоиск · IMDb · Трейлер · Постер · Похожие · Поделиться · Назад.
- [ ] «Добавить в список» → дальше меню сохранённой; в Data Jar запись с `origin` = `recommendation`, статус «Не смотрел».
- [ ] Другой похожий → «Смотрел + оценка» → 8 → отзыв → «Показать похожие?».
- [ ] Ещё один → «Не предлагать» → «Больше не предложу» → назад в список; в Rate виден в «Скрытые».
- [ ] Похожий, который уже в базе → открывается как сохранённая (меню с «Оценить»).
- [ ] Список похожих → «← Назад» → туда, откуда пришёл (Rate — список фильтра).
- [ ] «Спросить ИИ» → «Что спросить?» → ответ на русском без спойлеров, чат продолжается; закрыть → карточка.
- [ ] «Обновить данные» у `kp-`/`tt`-записи → «Обновлено»; оценка, статус, теги, заметка не изменились (1 запрос).
- [ ] «Обновить данные» у `ai-`записи → Lookup по названию: найдено → «Обновлено», ключ остался `ai-…`; отмена → ничего не записано.
- [ ] «В календарь» у тайтла с будущей премьерой → событие; повтор → «Премьера уже в Календаре».

### Movie Recommend (карточка)

- [ ] «Мой список» → тайтл → карточка с `| прогноз p` → «Назад» → список пересчитан.
- [ ] «Случайный» → сразу карточка → «Назад» → «Дальше?»: Ещё случайный / В меню.
- [ ] «По настроению» → тайтл → поставить «Смотрел» → «Назад» → тайтла нет в кешированном списке.
- [ ] «Новое» → тайтл → несохранённая карточка (1–2 запроса) → «Добавить в список» → «Назад» → список тот же (кеш, без нового вызова ИИ).
- [ ] Из карточки «Похожие» → список похожих; после того как все отмечены/скрыты → «Похожих не осталось» → меню.
- [ ] (если ИИ вернул ключи не из списка) «ИИ не подобрал из списка» → меню; (все «Новые» уже в базе) «Всё предложенное уже в базе» → меню. Специально не воспроизводится.

### Movie Tonight + виджет

- [ ] Запуск Movie Tonight → без меню сразу карточка одного тайтла из «Не смотрел»/«Смотрю».
- [ ] Несколько запусков → тайтлы меняются (случайный из топ-10).
- [ ] «Назад» в карточке → шорткат закрылся.
- [ ] Виджет на главном экране ([README](README.md#виджет)) → тап → та же карточка.
- [ ] (без кандидатов) «Список пуст — добавь через Movie Add» — на живой базе не проверять.

### Movies (голос, ~2 на add)

iPhone разблокирован, Siri на английском. С заблокированного — Siri не запустит (это известно, не баг).

- [ ] «Hey Siri, Movies» → «What do you want? Add a title, or ask what to watch.».
- [ ] «add Dune Prophecy» → Siri: «Added: Dune: Prophecy, 2024, series, IMDb x.». В Data Jar — статус «Не смотрел», `origin` = `manual`.
- [ ] Повтор → «Already in your list: Dune: Prophecy (2024).».
- [ ] Неоднозначное название → Siri зачитывает варианты («Which one?», + «None of these») → выбор голосом.
- [ ] Русское название голосом («brat two») → нашёлся «Брат 2» или варианты.
- [ ] Выдуманное → «Not found. Save as is?» → No → «Nothing added. Check the phone for details.».
- [ ] Будущий тайтл → в ответе «Premieres on <дата>.».
- [ ] «something light for tonight» → «Try: 1. … 2. … 3. …» с причинами по-английски.
- [ ] «what to watch, anime» при пустом аниме в списке → «Your watchlist is empty for that. Add something first.».
- [ ] Бессмыслица («hello») → «Say add and a title, or ask what to watch.» (или «Sorry, I didn't get that.»).
- [ ] Через AirPods — то же самое без экрана.

## 3. `ai_enabled` = `false`

Поставить в Data Jar `movies.settings.ai_enabled` = `false`.

- [ ] Add «Severance» → без «Что именно?», поиск сразу по вводу → превью (Отмена).
- [ ] Recommend «По настроению» / «Новое» → «ИИ выключен», остаёмся в меню. «Мой список» и «Случайный» работают.
- [ ] Card «Спросить ИИ» → «ИИ выключен». «Похожие» у `ai-`записи → «Похожих нет»; у записи с `kinopoisk_id` → similarMovies как обычно.
- [ ] Stats «Разбор вкуса (ИИ)» → «ИИ выключен».
- [ ] Movies «add Severance» → добавилось по шаблону `add …`; «what to watch» → топ-3 по вкусу с «IMDb x» вместо причин.
- [ ] Вернуть `ai_enabled` = `true`.

## 4. Ошибки poiskkino (в конце)

Испортить ключ: в `movies.settings.poiskkino_api_key` дописать лишний символ.

- [ ] Add новый тайтл → «poiskkino: 401 Переданный токен некорректен!» → превью «(нет в poiskkino)» из данных ИИ → «Отмена» (не сохранять).
- [ ] Card «Обновить данные» у записи с `kinopoisk_id` → «poiskkino: 401 …», данные в записи не изменились.
- [ ] Card «Похожие» с `kinopoisk_id` → «poiskkino: 401 …» → список от ИИ (или «Похожих нет»).
- [ ] Movies «add …» → «Nothing added. Check the phone for details.» или «Added … Not found on Kinopoisk, saved from AI data.» — если второе, удалить запись в Уборке.
- [ ] Удалить ключ целиком → Add → «Нет ключа poiskkino в movies.settings».
- [ ] Вернуть правильный ключ → Add/Lookup снова находит тайтл.

## Синхронизация (Movie Sync)

Не проверено ни разу: XML собран без Mac. Нужны воркер списка (`cloud/list-worker`, задеплоен) и ТВ с включённой синхронизацией на том же воркере. Ключ `sync_key` вписать руками в Data Jar, никуда не копировать. Состояние облака смотреть на ТВ или запросом `GET /v1/changes` (ключ — только в своём терминале).

### Подготовка

- [ ] `movies.settings`: `sync_enabled` = `true` (тип Boolean), `sync_url` = адрес воркера без `/` на конце, `sync_key` = ключ.
- [ ] В Data Jar нет `movies.sync` и `movies.episodes` (первый запуск с нуля).

### Выключено — ни одного запроса

- [ ] `sync_enabled` = `false` → Rate, Stats, Recommend, карточка открываются как раньше, без задержки и уведомлений; правка в карточке → в `movies.sync.queue.<key>` появилась строка, `movies.sync.cursor` нет.
- [ ] Rate → «Синхронизировать» → «Синхронизация выключена: movies.settings.sync_enabled», запросов нет (журнал воркера пуст).
- [ ] `sync_enabled` = `true`, `sync_key` удалён → «Movie Sync: нет sync_url или sync_key в movies.settings». Вернуть ключ.

### Забор (pull)

- [ ] На ТВ добавить фильм «К просмотру» и сериал со статусом «Смотрю», у сериала отметить серии S1E1–S1E3.
- [ ] iPhone: Rate → «Синхронизировать» → «Синхронизировано: тайтлов N, отметок серий M» (N ≥ 2, M ≥ 3), затем список «Все» с новыми тайтлами. В Data Jar: `movies.sync.cursor` > 0, `movies.sync.last_date` = сегодня, у записей есть `updated_ms`.
- [ ] Карточка сериала с ТВ: «Остановился: S1E3», меню «Уведомления: вкл».
- [ ] Повторный запуск Rate в тот же день → без запросов к воркеру (журнал воркера), без уведомлений.
- [ ] Удалить в Data Jar `movies.sync.last_date` → запуск Stats → изменения подтянулись молча (воркер получил `GET /v1/changes`).
- [ ] На ТВ поменять статус тайтла → iPhone: «Синхронизировать» → статус новый (LWW: облако новее).
- [ ] На ТВ «Убрать из списка» → iPhone: «Синхронизировать» → записи нет.
- [ ] На ТВ снять отметку серии S1E3 → iPhone: «Остановился: S1E2».
- [ ] Больше 500 изменений (если облако большое): за один запуск прочитаны все страницы, `cursor` = `next` последней.

### Запись с ключом `tmdb-…`
