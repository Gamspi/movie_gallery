# Movie Add — что поправить в шорткате на iPhone

Шорткат собран по [actions.md](actions.md); экспорт — [shortcut.xml](shortcut.xml). Номер `#N` — индекс действия в экспорте (в редакторе его нет — ищи по комментарию шага и соседним действиям). Сверено с экспортом.

**Статус (2026-10-26):** все исправления применены в [shortcut.xml](shortcut.xml) — проверено по экспорту (ключи, тексты, переменные, меню, If, баланс блоков, ссылки OutputUUID). Действия не добавлялись и не удалялись, поэтому индексы `#N` совпадают с текущим XML (при вставке действий индексы сдвигаются). Пункты помечены ✅; то, что в XML сделать нельзя, — ⚠️ с причиной. Список ниже — история.

## Ошибки

1. **#70** — комментарий «5.2 превью» → блок рейтингов → If `kp` из `rts` → после Text «КП …» стоит **Set Variable** `parts`, надо **Add to Variable** `parts`. Иначе КП затирает IMDb в превью. [actions.md:95](actions.md). ✅
2. **#155** — комментарий «10.1 карточка вернула похожие» → Repeat по `items` → If `imdb` из `rts` → после Text «`{label}` - IMDb …» нет **Set Variable** `label` = Text (как в #297). Иначе IMDb не попадает в метку списка. [actions.md:193](actions.md). ✅
3. **#201** — комментарий «11. уже смотрел?» → пункт **Смотрю** → **Text**. Сейчас `wayching`, надо `watching`. [README:52](README.md), [actions.md:242](actions.md), [data.md: Status](../data.md#status). ✅
4. **#202** — там же, **Set Dictionary Value** в `rec`. Сейчас ключ `stais`, надо `status`. Иначе статус «Смотрю» не сохраняется. [actions.md:243](actions.md). ✅
5. **#204** — там же, **Text** для `statusT`. Сейчас «Смотрел», надо «Смотрю». [actions.md:245](actions.md). ✅
6. **#286** — комментарий «17.1 список похожих» → Repeat → **Text** метки. Сейчас `{Repeat Item: title_ru} / {Repeat Item: title_ru} (…)`, вторая плашка должна быть `title_en` (как в #145). [actions.md:338](actions.md). ✅
7. **#290** — там же, **If** `rts` **has any value** → надо **does not have any value** (как в #149). Иначе рейтинги похожих всегда заменяются пустым словарём. [actions.md:343](actions.md). ✅

### Необязательное

20. **#215** — пункт «Смотрел» → If 1–10 → **Number** `[r]` → Set Variable `myR`. По [actions.md:256](actions.md) — сразу `Set variable myR to [r]`; работает и так. ⚠️ Необязательно, не применено: цепочка Number → Set Variable работает и так.
21. **#109** — «8. Дубли по ключу» → If `Value Exists` (Boolean) **is** — в экспорте значение не указано (по умолчанию True). Проверить в редакторе, что стоит **is True**. [actions.md:141](actions.md). ⚠️ В XML значение Boolean не задано (умолчание True) — задать ключ вручную нельзя без риска сломать разбор, проверить в редакторе на iPhone.
