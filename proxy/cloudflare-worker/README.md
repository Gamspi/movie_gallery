# Cloudflare Worker прокси для VideoGallery

Небольшой прокси на Cloudflare Workers. Приложение ходит на TMDB и торрент-трекеры через него, потому что напрямую они недоступны.

Схема адреса: `https://<имя>.workers.dev/<хост>/<путь>?<запрос>` превращается в `https://<хост>/<путь>?<запрос>`.

## Что разрешено

Разрешённые хосты (точное совпадение или поддомен), остальные получают 403:

- `api.themoviedb.org`
- `image.tmdb.org`
- `rutor.info` и `*.rutor.info`
- `rutracker.org` и `*.rutracker.org`

Методы: GET, HEAD, POST (остальные дают 405). Каждый запрос должен содержать заголовок `X-VG-Key` с секретным ключом, иначе 403. Редиректы upstream отдаются клиенту как есть (клиент сам повторяет запрос через прокси по абсолютному `Location`).

Торрентный трафик (пиры, DHT, трекеры по UDP, раздача) через прокси не идёт — только HTTP-запросы к API и сайтам.

## Развёртывание

1. Создайте аккаунт на https://dash.cloudflare.com (бесплатный тариф).
2. Откройте Workers & Pages, нажмите Create, выберите шаблон Hello World, задайте имя (оно станет частью `<имя>.workers.dev`), нажмите Deploy.
3. Нажмите Edit code, удалите весь код, вставьте содержимое `worker.js`, нажмите Deploy.
4. Откройте Settings, затем Variables and Secrets, добавьте Secret с именем `PROXY_KEY`. Значение — длинная случайная строка (например, сгенерированная менеджером паролей). Сохраните и сделайте Deploy заново.

Пока `PROXY_KEY` не задан, воркер отвечает 500 (закрыт по умолчанию).

## Проверка

```
curl -H "X-VG-Key: <ключ>" https://<имя>.workers.dev/
```

Ответ: `ok`. Без ключа или с неверным — 403.

Пример запроса к TMDB (подставьте свой ключ TMDB):

```
curl -H "X-VG-Key: <ключ>" "https://<имя>.workers.dev/api.themoviedb.org/3/configuration?api_key=<tmdb-ключ>"
```

Должен вернуться JSON с настройками TMDB.

## Настройка приложения

Добавьте в корневой `.env` (файл не коммитить):

```
PROXY_URL=https://<имя>.workers.dev
PROXY_KEY=<тот же ключ>
```

## Лимиты

Бесплатный тариф Cloudflare Workers: 100 000 запросов в сутки. Для личного использования этого достаточно.
