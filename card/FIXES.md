# Movie Card — что поправить в шорткате на iPhone

Шорткат собран по [actions.md](actions.md); экспорт — [shortcut.xml](shortcut.xml). Номер `#N` — индекс действия в экспорте (в редакторе его нет — ищи по комментарию шага и соседним действиям). Сверено с экспортом.

**Статус (2026-10-26):** исправления применены в [shortcut.xml](shortcut.xml) — при проверке скриптом (plistlib) все пункты уже были в экспорте; ссылки, UUID и баланс If/Menu/Repeat проверены. ⚠️ Номера `#N` ниже — индексы **до** правок: вставка `updated_date` (п. 13) и удаление Otherwise (п. 15) сдвинули индексы действий после #596 (в актуальном экспорте они больше примерно на +2 после п. 13, затем -1 после п. 15). Ищи по комментарию шага. Пометка ✅ — применено.

## Ошибки

1. ✅ **#87** — комментарий «12. Сразу похожие?» → **If** `Dictionary Value` is `simulat` → надо `similar`. Иначе вход `{key, auto:"similar"}` (из Movie Add после высокой оценки) открывает меню вместо «Похожих». [README:79](README.md), [actions.md:127](actions.md).
2. ✅ **#115** — комментарий «14.2 год тип длина возраст» → первый **Get Dictionary Value** из `rec`. Сейчас ключ `years`, надо `year`. Иначе год не показывается в карточке. [actions.md:161](actions.md).
3. ✅ **#120** — там же, **If** после Get Dictionary Value `type`. Сейчас вход — `Dictionary Value` следующего действия (#121, из `typeLabels`), надо — от #119 (`type` из `rec`). Иначе условие проверяет ещё не вычисленное значение и метка типа пропадает. [actions.md:166](actions.md).
4. ✅ **#196** — комментарий «14.7 заметка» → **Get Dictionary Value** из `rec`. Сейчас ключ `notes`, надо `note`. Иначе заметка не видна в карточке. [actions.md:249](actions.md), [data.md](../data.md#запись-moviesitemskey).
5. ✅ **#284–#286** — комментарий «14.10 меню несохраненной» → пункт **Похожие**. Сейчас Text `similar` → Set Variable `act`, надо **Number** `1` → Set Variable `doSimilar` (как в меню сохранённой, #238–#240). Иначе «Похожие» у несохранённой ничего не делает: `act` = `similar` нигде не обрабатывается. [README:113](README.md), [actions.md:341](actions.md).
6. ✅ **#312** — комментарий «15. статусы» → пункт «Не поедлагать» → **Text**. Сейчас `dismiss`, надо `dismissed`. Иначе в `status` пишется значение не из перечисления — метка не показывается, запись не исключается из рекомендаций и «Похожих». [README:88](README.md), [actions.md:370](actions.md), [data.md: Status](../data.md#status).
7. ✅ **#316** — там же, **Format Date** (ISO 8601). Сейчас на входе `{Date}{Date}` (дважды), надо один `{Date}` (#315). Иначе дата не разбирается и `updated_date` / `watched_date` пишутся мусором. [actions.md:374](actions.md).
8. ✅ **#365–#367** — комментарий «17. Теги» → после End If: **Format Date** стоит раньше **Date** и ссылается на неё, а **Set Value** `updated_date` берёт сырую `Date`. Надо: Date → Format Date (ISO 8601) от этой Date → Set Value `[Formatted Date]`. [actions.md:426](actions.md).
9. ✅ **#403** — комментарий «19. Спросить ии» → **Use Model** (Follow Up). В строке `Description:` плашка `rec` с ключом `discription`, надо `description`. Иначе ИИ не получает описание. [README:155](README.md), [actions.md:469](actions.md).
10. ✅ **#497** — комментарий «25. Обновить данные» → **List** полей. Последний пункт `update_date` → `updated_date`. Иначе `updated_date` после обновления не меняется. [README:98](README.md), [actions.md:593](actions.md).
11. ✅ **#566** — комментарий «31. Ключ: из lookup…» → **Match Text** `[a-zA-Z]`. Сейчас ищет в `yrK`, надо в `src`. Иначе в году латиницы нет никогда — ключ всегда `ai-<дата>-<год>` вместо `ai-<slug>-<year>`, и проверка дублей по ключу в других шорткатах не срабатывает. [actions.md:670](actions.md), [data.md: ключ](../data.md#ключ-записи).
12. ✅ **#569** — там же, первое **Replace Text** (` ` → `-`). Сейчас вход — `Updated Text` самого себя, надо — от Change Case (#568). Иначе slug пустой. [actions.md:673](actions.md).
13. ✅ **#596 →** — комментарий «30.2 пользовательское поле» → после Set Dictionary Value `added_date` → Set Variable `rec` нет **Set Dictionary Value** `updated_date` = `[now]` → **Set Variable** `rec` (как #595–#596). Иначе у сохранённой из рекомендации нет `updated_date`. [README:105](README.md), [actions.md:702](actions.md).
14. ✅ **#612** — комментарий «30.3 запись в data jar» → **Set Variable**. Сейчас имя `Skey`, надо `key`. Иначе после сохранения `key` пуст: карточка дальше читает `movies.items.` (не ту запись), оценка/отзыв пишутся мимо. [README:105](README.md), [actions.md:721](actions.md).
15. ✅ **#615–#620** — там же, **If** `saveStatus` is `dismissed`: сейчас внутри только уведомление, а **Dictionary** `{action: back}` → **Stop and Output** — в ветке Otherwise. Надо: уведомление → Dictionary → Stop and Output внутри If, Otherwise (#617) удалить. Иначе «Не предлагать» не закрывает карточку, а «Добавить в список» / «Смотрел + оценка» закрывают её сразу — «После оценки» (отзыв, «Показать похожие?») не выполняется. [README:111](README.md), [actions.md:725](actions.md).
16. ✅ **#701**, **#705** — комментарий «32.2 запасной путь» → оба **Use Model**, промпт «Похожие»: первая плашка `rec` с ключом `totle_en`, надо `title_en`. Иначе ИИ не знает, к какому тайтлу подбирать похожие. [README:137](README.md), [actions.md:820](actions.md).
17. ✅ **#710** — там же, после Get Dictionary Value `similar` из ответа Text-модели → **Set Variable**. Сейчас имя `similar`, надо `items`. Иначе запасной путь ИИ (Output Text) не даёт результата. [actions.md:829](actions.md).
18. ✅ **#749** — комментарий «32.3 исключить…» → второй Repeat по `items` → **Text** `|{Updated Text} {Repeat Item 2: …}|`. Сейчас ключ `yeat`, надо `year`. Иначе исключение по названию + году не срабатывает. [actions.md:869](actions.md).
19. ✅ **#754** — там же, **Get Dictionary Value** из `Repeat Item 2`. Сейчас ключ `kinopois_id`, надо `kinopoisk_id`. Иначе исключение по id не срабатывает — смотренное попадает в «Похожие». [README:127](README.md), [actions.md:874](actions.md).
